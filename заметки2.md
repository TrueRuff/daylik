# Заметки — сессия 2 (2026-10-23)

## Каркас приложения
- Утверждён стек UI: **vanilla JS** (ES-модули + классы).
- Создана папка `app/` — весь код отдельно от документов курсача. Vite + npm, хранение Dexie (IndexedDB), тесты Vitest.
- Структура: `src/core/` (models, storage, categorize, dayPlan, reminders) — мой блок; `src/ai/llmClient.js` — заглушка внешнего LLM (включится после получения ключа); `src/main.js` + `index.html` — минимальный UI (ввод → разбор).
- Реализованы и покрыты тестами (8/8 зелёные): гибридный разбор ввода (`categorize`: 3 правила + LLM-фолбэк при уверенности < 0.5) и календарь дня (`buildDay`: жадная упаковка дел в свободные окна, приоритет Н→Ж→П, невлезающее → postponed).
- **Грабли:** `\b` в JS-регулярках не работает с кириллицей (ASCII-only) — словарные правила переписаны без границ слов. Декси: два `.where()` подряд нельзя, второе условие через `.and()`.
- `npm test` и `npm run build` проходят. Коммит сделан.
