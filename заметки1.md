## Обговорено (продолжение — выработка требований)
- Опыт автора — почти нулевой; телефон Android. Всё делает один автор (разделение с Полиной — учебная условность).
- Решено: **PWA-приложение** (браузер + установка на Android), без сервера, данные локально в IndexedDB на каждом устройстве, без синхронизации. Язык — JavaScript, инструменты Vite/npm, хранение через Dexie, тесты Vitest.
- **Решение по платформе (уточнение): десктоп-версию делать через Electron** — та же JS-кодовая база, но собирается в настоящий .exe с установочным пакетом. Это, скорее всего, единственный вариант, честно закрывающий требования задания «настольный планировщик» + «создание установочного пакета» + Docker. На телефоне — PWA/PWA-обёртка.
- По заданию (перечитали: это не пример, а чёткие требования): **напоминания — обязательная функция темы**; нужны двоичная сериализация + JSON; язык в задании «например: C#, Java, C++, Python» — JS формально проходит, но подтвердить у Станкевича. В задании чужое ФИО и даты 2025 года — нужно своё задание.
- Автор не работал с Git — нужна инструкция/помощь по базовому циклу (add → commit → push) и настройка репозитория.
- «ИИ» — гибрид: локальные правила (регулярки + словарь) + бесплатный внешний LLM API (OpenRouter/Gemini) для незнакомых формулировок; при недоступности API работает на правилах.
- Приоритизация: этап 1 — пирамида категорий (быт → здоровье → развитие); этап 2 — оценка энергозатрат и фильтр по состоянию пользователя.
- Создан `требования.md` (черновик v1). Открытые вопросы: набор категорий/уровней, формат данных задачи, контракт API-модуля, vanilla vs фреймворк.
