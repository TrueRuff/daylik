# КПО курсач — контекст проекта

## Тема
«Алгоритмы обработки данных и интеграция API в системе планирования задач».
Одно приложение с одногруппницей Полиной (её блок — «Интерактивный пользовательский интерфейс для трекера задач с контролем состояний»). Мой блок — алгоритмы обработки данных и API.

Предметная область приложения: настольный планировщик задач для пользователей с СДВГ с локальным хранением и напоминаниями (по примеру задания).

## Требования (по образцу задания, БНТУ ФИТР)
- Исходные данные: Git + GitHub, высокоуровневый язык (C#, Java, C++, Python), IDE, пакетный менеджер.
- Календарный график: анализ источников и постановка задачи — 15%, проектирование и реализация — 50%, тестирование — 10%, оформление записки/графики/презентации — 25%.

## Структура пояснительной записки
1. Лист задания
2. Содержание
3. Введение
4. Обзор и описание предметной области, требования к ПО
5. Проектирование ПО (диаграммы классов, архитектура, паттерны проектирования)
6. Реализация ПО
7. Система контроля версий, удалённый репозиторий, стратегия разработки
8. Принципы ООП (абстракция, инкапсуляция, наследование, полиморфизм), паттерны
9. Средства ведения документации
10. Ресурсы приложения
11. Пользовательские библиотеки
12. Журналирование
13. Двоичная сериализация; XML/SOAP/JSON
14. Локализация и интернационализация
15. Обработка текста и регулярные выражения
16. Развертывание, установочный пакет, Docker
17. Unit-тестирование
18. Заключение
19. Список использованной литературы
20. Приложение А. Графическая часть (3–5 листов А4: интерфейс пользователя, схемы алгоритмов)
21. Приложение Б. Код программы

## Файлы проекта
- `ПРИМЕР ЗАДАНИЯ.docx` — образец задания другого курсача (Негруша О.Е., группа 10701123).
- `заметки<N>.md` — итоги сессий, число = номер сессии. Обновлять в конце каждой сессии, старое сокращать.

## Правила работы
- Постоянные инструкции держать здесь, в чате не повторять.
- Работать по одному разделу за сессию; редактировать существующие файлы, а не переписывать.
- В конце сессии кратко дописывать итоги в актуальный `заметки<N>.md`.
